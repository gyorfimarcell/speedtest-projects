# Cookie Banner (20 mins)

Create a cookie banner for the provided news website. You may modify the HTML and CSS. Your work should match the color and design of the existing website.

## Cookie Categories

The website uses three types of cookies:

- **Necessary** - Required for the website to function. The user must always consent to these.
- **Functional** - Enables enhanced functionality and personalization.
- **Marketing** - Used to deliver relevant advertisements.

## Cookie Banner

When the page loads and no consent preferences have been saved yet, a banner should appear at the bottom-right of the page with the following actions:

- **Accept All** - Accepts all three cookie categories.
- **Only Necessary** - Accepts only necessary cookies.
- **Settings** - Opens the cookie settings panel.

After the user has made a choice, the banner should close and the preferences should be saved to localstorage so the banner does not reappear.

## Cookie Settings Panel

The settings panel should appear as a centered modal with a dark backdrop.

The panel lists the three cookie categories with a toggle for each. Necessary cookies must always be enabled and the user must not be able to disable them. The panel includes a **Save** button that saves the selected preferences and closes the panel.

## Reopening Settings

The Cookie Settings button in the page footer should allow the user to reopen the cookie settings panel at any time.
