# Social Media Composer (15 mins)

Create a social media post composer centered on the screen.

Display a multiline text input area where the user can type a post. Below the text area, there is a live character counter, and a "Post" button.

The application should behave as follows:

- When the text area is empty, the counter displays 0 / 140.
- As the user types, the current character count is updated in real time.
- When the user has 20 or fewer characters remaining, the counter should turn yellow to indicate that the limit is approaching.
- When the maximum character limit is exceeded, the counter turns red, and the post button is disabled.
- When the post button is enabled and clicked, it should change its appearance to indicate that the post has been submitted (for example, by changing the text to "Posted!").
  After a few seconds, the text area is cleared, and the counter and button return to their initial state.
- When the text area is empty, the post button is also disabled.
