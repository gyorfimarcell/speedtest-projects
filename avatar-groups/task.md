# Avatar Groups (10 mins)

Create avatar group rows using only CSS. Do not modify the HTML file.

## Avatar Images

Display the avatar images as circles with a white border.

## Stacked Group Layout

Within each `.group`, the avatars should overlap one another so they appear stacked in a pile. The first avatar in the group should not be shifted.

## Overflow Groups

If a group contains 6 or more avatars, only the first 5 avatars should be visible. A circular badge displaying the remaining count should appear at the end of the group — for example, if a group has 8 avatars, show the first 5 images and a "+3" badge.

Groups with 5 or fewer avatars should display all images without a badge.

## Hover Animation

When the user hovers over a `.group`, the avatars should spread apart from their stacked position with a smooth animation. When the cursor leaves, they should return to their stacked state.
